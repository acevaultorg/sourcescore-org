## Merge/standalone decisions — the reasoning per cluster

### Why MERGE these (bundle compound > separate brands)

🅰 **holdlens.com (Holdings cluster, 4)** — All four concepts share the same EDGAR data pipeline + same reader intent ("what big investors own"). Internal-linking compound is huge (every 13F ticker page links to its 13D/G activist filings + DEF 14A vote events). Splitting would lose ~30% bundle value.

🅱 **secfilings.io (Events cluster, 5)** — Form 4 + 8-K + Ch11 + Enforcement + 10-K all share "what public companies REPORT TODAY" intent. Different from holdlens which is "what's owned." 2-brand split (ownership vs. events) gives each its own SEO authority + cleaner brand without losing within-cluster compound.

🅲 **sourcescore.org (AI-Citation cluster, 4)** — Universal Index + Discipline Score + Modern Reference + Velocity Tracker all use the same source-quality-data backend. Operator paste-URL becomes the entry — every sub-tool runs against the same scored URL DB. Bundle compound critical because no single sub-tool is APS 30+ alone.

🅳 **readinglist.school (Reading cluster, 4)** — already live; sub-extensions reuse same book-DB + grade-level data. Back-to-school seasonal stacks all four into peak window.

🅴 **teardown.directory (CRO Teardown, 5)** — Pricing/Landing/Onboarding/Hero/Empty all SAME audience (SaaS founders), SAME format (per-company analysis with screenshots), SAME content cadence (~weekly editorial). Maximum bundle compound (×1.25) because 5-concept stack on tight-audience domain. **Domain choice: `teardown.directory`** beats `pricingteardown.com` because parent brand is extensible (future /podcast-teardown/, /onboarding-teardown/) without dilution.

🅵 **gardenfleet.io (Garden cluster, 4)** — All four use USDA + NOAA data. Audience overlap: home gardeners. Internal-linking high (companion-plant-X page → hardiness-zone-of-X → frost-dates-of-X → calendar-for-X). Single domain stack ×1.20.

🅶 **langlevels.io (Language Level cluster, 3)** — CEFR + Vocab + Best-Test all serve self-directed language learners. Different audience than gradedreaders (parents/teachers) so kept separate from #9.

🅷 **fermentcalc.com (Fermentation cluster, 3)** — already live; salt/time + brine + kombucha share NCHFP safety-cite floor + home-fermenter audience. Coffee Brew folded out (different audience).

### Why STANDALONE these (audience-divergence > bundle compound)

🅸 **gradedreaders.io** — Foreign-language reading FOR PARENTS/TEACHERS picking books for students. Different persona than langlevels (self-directed adult learners). Different SERP. Different content tone. **Standalone wins.**

🅹 **sousvidedb.com** — Sous-vide audience (precision-cooking enthusiasts, often higher-income foodies) is structurally different from fermentcalc audience (home-preserving frugal/safety-focused). Different SERPs. **Standalone wins.**

🅺 **conversionbench.com** — Live CR benchmark DB with different content cadence (data-update annually) than teardown.directory (per-company weekly editorial). Same audience but different format = different SEO pages, different return frequency. **Standalone wins.**

🅻 **llmcost.io + llmfrontier.io** — Could merge as "LLM Decision Tools" parent. BUT the SERPs are distinct: cost-per-task queries are commercial-intent (cost-comparison shoppers), latency-quality is technical-evaluation (engineers picking models). Audiences overlap ~30%. **Standalone wins** — better SEO authority per intent.

🅼 **canningaltitude.io** vs fermentcalc — different safety profile (canning is FDA-regulated thermal preservation; fermentcalc is microbial). Different cite-floor. Different audience risk-aversion. **Standalone wins.**

🅽 **instantpotdb.io** — 1 billion Instant Pot owners ≠ fermenter audience. Different cooking method. Mass-market vs. niche. **Standalone wins.**

🅾 **inkcalc.io / breedmatch.io / typairs.io / mrrgrowth.io / corpcompare.io** — all sit alone (Body / Pets / Design / SaaS / Legal verticals; no natural cluster mate in top 30 picks).
